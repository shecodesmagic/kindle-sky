# Data sources

All files here are generated by `tools/build_catalog.py` from
[d3-celestial](https://github.com/ofrohn/d3-celestial) by Olaf Frohn
(BSD 3-Clause, see `LICENSE-d3-celestial.txt`), pinned to commit
`7e720a3de062059d4c5400a379146a601d9010e0`. The builder refuses to run if any
input's SHA-256 differs from the one recorded in the script.

| File | Contents |
|---|---|
| `stars.csv` | Hipparcos stars to magnitude 5.5, plus every star used by a constellation line (down to 5.9). J2000 positions. |
| `lines.json` | Constellation figures as lists of HIP numbers. Each vertex was matched to a catalogue star within 0.05°, so every line ends on a star. |
| `constellations.json` | Latin names and label positions for the 88 constellations (Serpens is split in two). |
| `starnames.json` | Proper names of stars brighter than magnitude 2.5. |

One manual addition: Mira (omicron Ceti, HIP 10826) is a variable star
missing from the source star list, but Cetus' lines run through it. It is added
at a nominal magnitude of 4.0.

Proper motion is not applied. The fastest bright star (Arcturus) has moved
about 1 arcminute since J2000, which is about 1/60 of the 1° accuracy target.

Planet, Moon and Sun positions come from JPL's DE421 ephemeris (valid
1899–2053), installed from the `skyfield-data` wheel, whose SHA-256 is pinned in
`requirements.txt`.

The fonts in `../fonts/` are DejaVu Sans (Bitstream Vera license, see
`LICENSE-DejaVu.txt`). They are bundled so CI, a Raspberry Pi and your Mac all
render identical images.
